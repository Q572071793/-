# 🎲 PickerBot - 年会抽奖系统

一个功能强大、界面美观的纯前端抽奖系统，专为年会和各种活动设计。

## ✨ 功能特点

### 🎯 核心功能
- **🎲 智能抽奖** - 支持逐个抽奖和批量抽奖模式
- **👥 人员管理** - 灵活导入和管理参与人员
- **🏆 奖项设置** - 自定义奖项名称和数量
- **📊 中奖记录** - 完整记录所有中奖信息
- **📤 数据导出** - 支持CSV/JSON/TXT格式导出

### 🎨 界面特色
- **现代化设计** - 渐变色彩和卡片式布局
- **响应式界面** - 适配不同屏幕尺寸
- **流畅动画** - 丰富的视觉反馈效果
- **主题定制** - 支持背景和标题自定义

### ⚙️ 高级功能
- **批量操作** - 支持批量导入和删除
- **音效控制** - 可选的音效反馈
- **数据持久化** - 本地存储，刷新不丢失
- **键盘快捷键** - 支持空格键开始/停止

## 🚀 快速开始

### 📥 安装使用
1. **克隆或下载项目**
   ```bash
   git clone https://github.com/your-username/pickerbot.git
   ```

2. **直接打开使用**
   - 双击 `index.html` 文件
   - 或在浏览器中打开 `index.html`

3. **本地服务器（可选）**
   ```bash
   # 使用Python
   python -m http.server 8080
   
   # 或使用Node.js
   npx serve .
   ```

### 🎯 基本使用
1. **设置奖项** - 点击设置按钮添加奖项
2. **导入人员** - 手动输入或文件导入参与人员
3. **开始抽奖** - 点击开始按钮进行抽奖
4. **导出记录** - 抽奖结束后导出中奖记录

## 📋 详细功能

### 🏆 奖项管理
- **自定义奖项** - 设置奖项名称和中奖人数
- **奖项排序** - 支持拖拽调整奖项顺序
- **预设模板** - 提供常用奖项模板
- **实时统计** - 显示各奖项剩余名额

### 👥 参与人员
- **多种导入方式**
  - 手动输入（每行一个姓名）
  - 文件导入（支持.txt和.csv格式）
  - 示例数据（快速体验功能）
- **批量管理**
  - 批量选择和删除
  - 清空所有人员
  - 防止重复中奖设置

### 🎲 抽奖模式
- **逐个模式** - 一个一个抽取并展示
- **批量模式** - 一次性展示所有中奖者
- **智能分配** - 自动按奖项顺序分配
- **防重复** - 避免同一人多次中奖

### 📊 中奖记录
- **完整记录** - 包含姓名、奖项、时间
- **多种导出格式**
  - CSV格式 - 适合Excel处理
  - JSON格式 - 适合程序处理
  - TXT格式 - 简单易读
- **自定义导出** - 可选择导出内容

### 🎨 个性化设置
- **系统标题** - 自定义抽奖系统标题
- **背景图片** - 支持上传自定义背景
- **主题切换** - 提供多种预设主题
- **动画效果** - 可调节动画速度和时长

## 🛠️ 技术栈

- **HTML5** - 语义化标签结构
- **CSS3** - 现代样式和动画
- **JavaScript** - ES6+ 原生实现
- **Font Awesome** - 图标库
- **Google Fonts** - 字体优化
